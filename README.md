A one-page newspaper front page summing up the world's news of **Friday 20 November 2026**: the first-ever Trump–Xi–Putin trilateral summit in Shenzhen, the world court's genocide ruling on Myanmar and the Rohingya, Trump pushing the Iran decision to 2027, Cyclone Akvan's landfall in Odisha, Europe opening to talks with Russia, Japan's Hayabusa2 landing called off, and GTA 6 outselling a $1.8bn epic. Every story was verified against real reporting from the morning of 20 November 2026 (Reuters, BBC, CNN, Le Monde, The Hindu, Space.com, Council on Foreign Relations). The poster is drawn entirely in code — no photos, no downloaded artwork.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` (Python 3.13, standard library only) copies `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it twice and the output is byte-identical. `draw_poster.py` is the script that drew the poster with PIL — re-run it to regenerate `entry.png` from scratch.
